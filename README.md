# Koules

A web port of [Koules](https://www.ucw.cz/~hubicka/koules/English), the classic 1995 arcade game by Jan Hubička — plus **Koules 2**, a modern sequel with 15 new physics ball types.

## Games

- **Koules 2** (`koules2.html`) — Modern sequel with glow/particle visuals, 15 new ball types, 50-level campaign, 4 game modes, boss battles, and interactive environment elements
- **Koules** (`koules.html`) — Faithful port of the original with physics matching the C source, embedded sound effects, legend overlay, and mobile support
- **Tic-Tac-Toe** (`index.html`) — Classic tic-tac-toe with a light theme
- **Worm** (`worm.html`) — Classic snake/worm game

## Koules 2 — New Ball Types

| Ball | Behavior |
|------|----------|
| 💣 Bomb | Explodes on impact, chain-reacts with other bombs |
| 🧬 Split | Divides into smaller, faster balls when hit |
| 🌀 Gravity | Creates a gravity well pulling everything toward it |
| 🧲 Magnetic | Alternates between attracting and repelling the player |
| 🏐 Spring | Super bouncy with near-perfect elasticity |
| 🛡 Field | Projects a force field that deflects objects |
| 🔘 Switch | Toggles fields, gates, and mechanics when touched |
| 👻 Ghost | Phases in and out of solidity, invulnerable when ghostly |
| ⛓ Chain | Connected balls that swing like a flail |
| ⏱ Time | Creates a temporal field that slows everything inside |
| 💣 Mine | Stationary, detonates on proximity |
| 🌀 Portal | Linked pairs that teleport objects with preserved momentum |
| ❄ Ice | Slides with low friction, freezes objects on hit |
| 🔥 Fire | Leaves a damaging trail, accelerates over time |
| 👹 Boss | Multi-phase boss with health bar and attack patterns |

## Play

Open any `.html` file directly in your browser. No server or dependencies required.

### Controls

- **Desktop**: Arrow keys or WASD to move, Space to pause
- **Mobile**: Virtual joystick (bottom-left), tap to interact
