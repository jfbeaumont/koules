# Koules

A web port of [Koules](https://www.ucw.cz/~hubicka/koules/English), the classic 1995 arcade game by Jan Hubička.

## Games

- **Koules** (`koules.html`) — Full port with physics, sound, and all original game objects
- **Tic-Tac-Toe** (`index.html`) — Classic tic-tac-toe with a light theme
- **Worm** (`worm.html`) — Classic snake/worm game

## Play

Open any `.html` file directly in your browser. No server or dependencies required.
